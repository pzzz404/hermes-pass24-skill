# Тексты для GitHub

## Короткое описание

Русский: Скилл Hermes для заказа автомобильных пропусков PASS24.online через Telegram — текстом или голосом.

English: Hermes skill for ordering PASS24.online vehicle passes from Telegram text or voice requests.

Актуальный контракт авторизации: мобильный API PASS24 принимает номер аккаунта в поле `phone`. Устаревшие версии API и документации использовали поле `email`.

Current authentication contract: the PASS24 Mobile API accepts the account number in the `phone` field. Older API versions and documentation used `email`.

## Социальный preview

### Русский

Отправьте Hermes текстовую или голосовую заявку в Telegram — он распознает её и оформит автомобильный пропуск в PASS24.online.

### English

Send Hermes a text or voice request in Telegram to create a PASS24.online vehicle pass.

## Публикационный комментарий

Проект является независимой неофициальной интеграцией. Это Hermes skill: Hermes принимает сообщения и голос в Telegram, распознаёт заявку и вызывает локальный CLI для PASS24. Репозиторий не содержит токенов, паролей, номеров телефонов, chat ID или данных пропусков.
